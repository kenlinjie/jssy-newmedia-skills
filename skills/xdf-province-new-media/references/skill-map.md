# 场景与技能目录

按用户要交付的结果选择；只读对应技能。各技能的软件、账号与素材要求在其正文中现场验证。

| 场景 | 技能入口 | 使用条件 |
| --- | --- | --- |
| AI环境配置 | [ai-environment-setup](../../ai-environment-setup/SKILL.md) | Mac／Windows；安装时实时核验官方版本 |
| 公众号写稿与排版 | [gzh-design](../../gzh-design/SKILL.md) | Python 3；检索与头图按当前宿主实际能力使用 |
| 团队通用日报 | [daily-report-universal](../../daily-report-universal/SKILL.md) | 本人历史日报与真实工作素材；钉钉读取用 dws |
| 公开抖音账号对标 | [douyin-benchmark](../../douyin-benchmark/SKILL.md) | ego Lite；Node.js；只采公开资料 |
| 文案修改与去AI腔 | [write](../../write/SKILL.md) | 用户原稿或明确的写作事实 |
| 文风与口播长期学习 | [voice-loop](../../voice-loop/SKILL.md) | 授权语料；每人单独本地 profile，不包含人物数据 |
| 看视频与按时间点复盘 | [watch](../../watch/SKILL.md) | Python、ffmpeg、ffprobe；无字幕时需要本地转写运行时 |
| 本地中文音视频转写 | [local-sota-transcription](../../local-sota-transcription/SKILL.md) | 仅 Apple Silicon Mac；uv、本地模型与语言资源按需配置 |
| 口播视频剪辑与包装 | [remotion-talking-head](../../remotion-talking-head/SKILL.md) | Node.js、Remotion、授权源视频；生成视频时再安装依赖 |
| 网页演示与培训分享 | [guizang-ppt-skill](../../guizang-ppt-skill/SKILL.md) | HTML演示；脚本验收需要 Node.js；页面动效可离线降级 |
| 可编辑PPT与PPTD项目 | [open-kimi-ppt](../../open-kimi-ppt/SKILL.md) | Python、Node.js 18+、Chromium；导出需访问 Kimi 官方资源 |
| SVG转可编辑PPT | [ppt-master](../../ppt-master/SKILL.md) | Python虚拟环境与 requirements.txt；可选配图另需对应能力 |
| 联网检索与平台资料读取 | [agent-reach](../../agent-reach/SKILL.md) | 优先当前可用的连接器；外部CLI与账号按需核验 |
| 网页正文转Markdown | [defuddle](../../defuddle/SKILL.md) | Defuddle CLI；需要时再安装，不代表已有登录态 |
| Obsidian笔记操作 | [obsidian-cli](../../obsidian-cli/SKILL.md) | Obsidian与CLI；用户主动打开目标知识库后使用 |
| Obsidian笔记格式 | [obsidian-markdown](../../obsidian-markdown/SKILL.md) | 用户指定知识库；无外部账号依赖 |
| Obsidian数据视图 | [obsidian-bases](../../obsidian-bases/SKILL.md) | Obsidian Bases；指定笔记与字段 |
| Obsidian思维画布 | [json-canvas](../../json-canvas/SKILL.md) | Obsidian或兼容JSON Canvas的工具 |
| 钉钉消息、文档、AI 表格、日历等 | [钉钉 CLI 官方站](https://open.dingtalk.com/dingtalk-cli) | 外部工具；按官网当前说明安装、授权并接入官方技能 |
