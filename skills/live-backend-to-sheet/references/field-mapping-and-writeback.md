# 字段口径与写回

读取目标表后使用本参考。只载入对应目标的操作说明；软件、Schema 和页面选择器均以当前环境为准。

## 先确定“一行代表什么”

先看目标是单场直播明细、账号每日汇总还是周期汇总。单场数据不能直接塞到汇总行。若要汇总，优先读取后台相同周期的官方汇总；无法取得时，与老师明确各指标的聚合口径。跨场次去重人数不能简单相加，平均值不能未经权重直接平均。

字段映射至少记录：后台指标原名、目标列、含义、原单位、目标类型／单位、转换方式、精度和缺失状态。表里存在字段不代表后台一定有同名数据，以下只是常见辨别点：

| 后台显示 | 核对后才能填入 | 常见歧义 |
| --- | --- | --- |
| 开播时间、结束时间 | 直播日期、开播／结束时间 | 时间戳用哪个时区；跨午夜的场次日期按目标口径确定 |
| 直播时长 | 单场直播时长 | 秒、分钟、小时或 `时:分:秒`；不能拿累计观看时长替代 |
| 观看人数 | 观看人数 | 去重人还是观看人次，单场还是周期去重 |
| 观看人次 | 观看人次 | 不能换名填写为去重人数 |
| 曝光次数／人数 | 同口径的曝光列 | 次数不等于人数，曝光不等于进入直播间 |
| 平均在线、最高在线 | 平均在线、峰值在线 | 两项分别填写，不能互补 |
| 新增关注 | 直播新增关注 | 累计粉丝数不能替代新增关注 |
| 转化率、点击率 | 对应比率字段 | 分母口径，以及目标保存 `0.125` 还是显示 `12.5%` |
| 加微、留资、进群 | 对应业务列 | 后台没有就保留缺失，不从点赞、粉丝等指标推算 |

保留明确的 0；`—`、未展示、无权限和未结算都保留其真实状态。目标不允许空值时先请老师确定处理方法。

`1.2万` 等缩略数值保留其近似精度，不能直接当精确 `12000`。优先取后台官方精确导出；只有老师接受近似值且目标能记录其精度时，才按约定填入并标注。字段不具备精度表达方式时，不能自行增加列。

正在直播、结束但未结算、后台数据更新中的记录标记为暂定，老师接受后才填。后续修订按更新授权处理，不能悄悄覆盖历史记录。

## 钉钉表：只用 dws

安装、本人授权与官方技能从 [钉钉 CLI 官方站](https://open.dingtalk.com/dingtalk-cli)获取；命令按 [官方参考](https://open.dingtalk.com/dingtalk-dev/wiki)和当前 CLI 帮助／叶子 Schema 核验。

1. 先识别链接是 AI 表格、电子表格还是文档附件，使用对应官方能力；不要把链接字符串猜成表 ID。核验 CLI 当前授权身份、组织和目标权限。后台账号与钉钉登录是两项独立状态。
2. 读取具体数据表／工作表、字段及现有记录，完成映射和场次查重。仅有文档访问权不表示有编辑权。
3. 按当前 Schema 写入已授权的记录，保留返回的记录 ID，再按 ID 或键读取目标实际值。不发消息、不调整共享权限、不安装无关应用。

没有 `dws`、授权未完成或 CLI 尚不能操作该表类型时，说明具体缺口和官网入口。可先交付数据预览，待老师完成配置后继续；不能改用 ego Lite、Chrome 或其他连接器绕过钉钉入口，也不能把预览称作填表成功。

## 本地 Excel：后台处理文件

确认绝对文件路径、实际工作表和表头。优先用当前可用的文件工具或兼容库读写，不自动启动 Excel 或 WPS。

修改原件前在项目外私人目录保留备份。读取公式与样式，保留现有列顺序、格式、公式、合并单元格和其他工作表；只写已授权的数据区域。用当前文件版本计算追加位置，不只依赖可能被格式撑大的 `max_row`。

先在临时副本完成修改并重新打开核验，确认公式等结构保留且原件未被他人改动，再替换目标或按老师要求另存。遇到宏、受保护区域或当前库无法保真的文件，暂停该写入，说明所需支持；不以破坏格式的转换来完成。

通过文件工具重新读取每个写入行，检查场次键、日期类型、时长／比例格式和实际值。另存新文件时明确交付新路径，不能声称原文件也已同步。

## 其他在线表：ego Lite 可见编辑界面

在同一 TaskSpace 中读取目标标题、工作表、账号及编辑状态。需要保留源后台时才新建第二个 Page，不为目标表另建 TaskSpace。

语义明确的页面用当前快照引用；画布型表格用截图和键盘操作。先在计划填写的位置写一行并读回，确认选中区域、列顺序、日期／百分比类型和粘贴行为，再继续。批量粘贴防止制表符或换行导致错列；不能只看“已保存”就认定值正确。

目标要求老师登录、切换组织或申请编辑权限时交回操作。其他账号的表、只读副本或同名不同表不能代替已确认的目标。重新打开或重试前按场次键读取已落表行，避免重填。
