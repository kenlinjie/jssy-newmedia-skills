# 五版效果图审稿门槛

只在制作选版效果图时读取。本阶段的交付是可评审的视觉方向，不是整片。

## 先从内容出发

在搜索模板前，从内容地图选出一个代表性强、画面空间具有代表性的时点。效果图必须同时回答：

- 观众第一眼看什么？
- 这张图强化了哪句真实观点、数字或关系？
- 图形放在哪里不会挡脸、手势、产品、原字幕或平台 UI？
- 这种视觉机制能否自然扩展到整片，而不是只适合封面？

优先使用同一张代表帧比较五版；某种机制确实需要另一帧时，在审稿说明中写清原因和时间点。

## A–C：三个热门网络模板方向

### 检索

1. 使用 `agent-reach` 搜索当前仍可访问的官方模板市场、作者页、官方示例或高使用量开源模板。
2. 浏览器核实时优先 ego Lite。记录检索日期和直达详情页，不链接搜索结果页。
3. 优先与 talking-head、vertical reels、kinetic typography、callout、lower third、editorial annotation、data visualization 等实际任务相符的热门分类。

### 热门证据

每个候选至少保存一类可核验信号：

- 平台明确标注 Popular、Trending、Best Seller、Most Downloaded 或同类榜单；
- 可见的下载量、收藏量、销量、评价数与评分；
- 开源项目相对同类显著的 stars、forks、使用案例或维护活跃度；
- 官方精选、编辑推荐或作者代表作，并有可见社区使用证据。

只出现在搜索结果、没有使用量/榜单/评价证据、作者和维护状态不明的模板视为冷门或证据不足。不要为了凑够三个而使用。继续扩大搜索；仍找不到时明确报告缺口，不得把冷门模板伪装成热门。

### 差异化

A、B、C 必须是三种视觉机制，而非同一模板的三种配色。建议从以下机制中按内容选择，不固定套用：

- 边缘批注 / 杂志编辑式标题；
- 动态大字 / 数字推进 / 关键词节奏；
- 关系图、时间轴、对比、图表或轻量 B-roll/PiP。

模板网页只提供视觉证据。最终效果图要在当前视频代表帧上重建其布局和视觉逻辑，使用当前视频的真实文字与数据；不要把模板商城截图直接当方案。

## D–E：两个原创生图方向

使用 `imagegen`，把代表帧作为构图/人物位置参考，生成两种明确不同的设计参考图。提示词应包含：

- 目标比例与平台；
- 主体、脸和原字幕需要保护的区域；
- 本条视频的真实核心观点；
- 视觉机制、材质、字阶和情绪；
- 禁止改变人物身份，禁止把生成文字当成最终准确文字。

D、E 是概念图。生图中的中文只看布局，不视为定稿；最终中文必须由 Remotion 确定性渲染。若图像生成不可用，报告阻塞，不要悄悄用两个额外网络模板替代。

## 五张用户可评审效果图

每张效果图必须：

- 与最终画布同尺寸、同比例；
- 使用真实 A-roll 画面或从真实画面衍生的明确参考；
- 展示一个完整稳定帧，不用安全区辅助线污染用户预览；
- 左上角或文件名标清 A–E，但标签不能被误认为最终成片元素；
- 不遮脸、不压原字幕、不把关键文字贴近边缘；
- 能看出主标题、辅助信息和至少一个非文字视觉机制。

另生成一张联系表，顺序固定 A、B、C、D、E。文件名建议：

```text
02-style-review/
├── frames/
├── A-online-popular-<slug>.png
├── B-online-popular-<slug>.png
├── C-online-popular-<slug>.png
├── D-original-imagegen-<slug>.png
├── E-original-imagegen-<slug>.png
├── contact-sheet.png
└── STYLE_REVIEW.md
```

## STYLE_REVIEW.md 必填项

每版记录：

- 编号和方向名；
- 使用的源视频时间点；
- 这版如何服务内容；
- 主要构图、字体、色彩和运动设想；
- 安全区与人物/字幕避让；
- A–C 的直达来源、平台、检索日期和热门证据；
- D–E 的生图模型/工具与“仅作参考”声明；
- 是否使用付费或需授权资源；
- 当前状态：`待选`、`需修改`、`已选`、`淘汰`。

## 停止条件

把五张图和联系表展示给用户，简要指出每版差异，然后停止。不得在同一轮继续创建整片工程、完整 Motion Graphics 批次或最终渲染。用户没有明确选中 A–E 时，本阶段只能保持 `style_review_pending`。
