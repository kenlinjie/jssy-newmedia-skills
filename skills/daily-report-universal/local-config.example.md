# local-config.md — 本地配置与个人画像

> 本文件是 daily-report-universal 的本地配置，只属于当前使用者本人。
> 未初始化时字段为 `〈待填写〉`；首次使用本 skill 时会自动读取你的钉钉历史日报，生成「个人画像」并写入这里。
> 初始化后，本文件即"你的日报助手设置"；**不要连同它转发给他人**；分发本 skill 时保持本文件为空白模板。

## 个人画像（由你的历史日报自动推导，初始化时生成）

- 日报模板与结构：〈待填写〉（模板名、字段块及顺序、编号与排版习惯）
- 固定事项：〈待填写〉（几乎每篇都出现的工作条目）
- 工作主线：〈待填写〉（反复出现的工作主题及大致频次）
- 阶段变化：〈待填写〉（工作重心在时间上的演变）
- 复盘维度与叙述方式：〈待填写〉（按什么维度组织、分条还是成段）
- 表达与格式特征：〈待填写〉（口吻、句子粒度、常用表达、数字与日期格式、称呼习惯）
- 数据习惯：〈待填写〉（常出现的数据字段即数据源方向；从不出现的字段按红线处理；样本量）
