# 同事上手

[国内镜像下载完整项目](https://gh-proxy.org/https://github.com/kenlinjie/xdf-province-new-media-skills/archive/refs/heads/main.zip)。此链接固定跟随主分支，后续更新继续使用同一入口。镜像不可用时，可使用项目仓库的 GitHub 原始下载。

用已有的 agent 打开本项目，先读 `AGENTS.md`。软件还未配置时从 `ai-environment-setup` 开始，不需要先把全部技能装完。

## 常见任务

- 公众号：用 `gzh-design` 处理原稿、选择头图与排版。政策事实按对应流程核验。
- 公开抖音对标：用 `douyin-benchmark`，保留采集完整性与证据边界。
- 视频：用 `watch` 复盘；纯转写用 `local-sota-transcription`；剪辑包装用 `remotion-talking-head`。
- 日报：用 `daily-report-universal`，先按本人真实历史认人，再给当天草稿。
- PPT：可编辑文件用 `ppt-master` 或 `open-kimi-ppt`；网页演示用 `guizang-ppt-skill`。
- 钉钉：直接从[钉钉 CLI 官方站](https://open.dingtalk.com/dingtalk-cli)安装、授权并接入官方技能，业务统一使用 `dws`。

## 安装到自己的工具

让 agent 在项目目录执行以下命令；Python 需要 3.9+：

```bash
python3 scripts/skillpack.py install --target workbuddy --profile core
python3 scripts/skillpack.py install --target workbuddy --profile core --apply
```

第一条预览，第二条实际复制。`--target` 可换为 `agents`、`codex` 或 `claude`；`--profile team` 选择全部技能。只装一个用 `--skill gzh-design`，自选目录用 `--directory`。已有同名技能会保留，安装后新开或重载会话。

没有 Python 时，让 agent 将所需完整技能目录复制到其支持的技能目录，也可使用宿主的目录导入入口。

## 个人配置

项目只放空白模板。个人画像、历史日报、录音、授权语料和业务数据在本人指定的项目外目录维护，不放入共享项目。日报技能独立安装后可在自己的技能目录创建配置；升级和重装保留已有配置。

技能不自带办公账号、软件运行时或模型。真实业务执行前，按所用技能检查软件、账号、组织权限及当次目标，不把“技能已安装”当作“账号已连通”。

```bash
python3 scripts/skillpack.py check
python3 scripts/privacy_check.py
```

上面的检查覆盖文件完整性与已配置的隐私规则，公开来源与许可见项目根目录的 `THIRD_PARTY.md`。
